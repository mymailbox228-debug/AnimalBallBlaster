# Как получить APK без установки программ

1. Откройте https://github.com и войдите в аккаунт (или создайте бесплатный).
2. Нажмите **New repository**. Название: `AnimalBallBlaster`. Выберите **Public** или **Private**, затем **Create repository**.
3. В новом репозитории нажмите **Add file → Upload files**.
4. Распакуйте архив проекта на устройстве, выделите и загрузите ВСЕ файлы и папки проекта, включая скрытую папку `.github` и файл `export_presets.cfg`. Если интерфейс телефона не показывает скрытые файлы, загрузите папку `.github` отдельно через **Add file → Create new file** и создайте файл `.github/workflows/build-android.yml`, вставив содержимое одноимённого файла из архива.
5. Нажмите **Commit changes**.
6. Откройте вкладку **Actions** репозитория. Если GitHub спросит разрешение на запуск workflows, подтвердите.
7. Откройте запуск **Build Android APK** и дождитесь зелёной галочки. Обычно это занимает несколько минут, иногда дольше.
8. Внизу страницы запуска найдите **Artifacts** и нажмите `AnimalBallBlaster-Android-APK`. Скачается ZIP-архив; внутри будет `AnimalBallBlaster.apk`.
9. Откройте APK на Android и разрешите установку из этого источника, если система спросит.

Если сборка завершится красным крестиком, откройте её, скопируйте последние строки ошибки из шага **Import project and export APK** и пришлите сюда — помогу исправить.

## Важно
- APK будет debug-подписанным тестовым APK, подходящим для установки и проверки на Android, но не для публикации в Google Play как релизная сборка.
- Для GitHub Actions используется контейнер `barichello/godot-ci:4.3.0` с Godot и Android-инструментами.
- Не загружайте в публичный репозиторий личные ключи подписи или пароли. В этом проекте используется временный debug-ключ, который создаётся автоматически в среде сборки.
